# 쇼핑 키워드 (DRESSCODE M · 골라줌)

아로하 자동발행과 따로 돈다. 저장소 Secrets 의 네이버 검색광고 키를 빌려 쓰기만 한다.

1. `keywords/requests/<이름>.txt` 를 만든다. 한 줄에 검색어 하나, 첫 줄 = 브랜드+제품.
   ```
   한경희 스팀청소기
   스팀청소기
   핸디스팀청소기
   ```
2. 커밋·푸시하면 `shop-keywords` 작업이 돈다.
3. 결과: `keywords/results/<이름>/00_키워드.txt` (작업이 커밋함 → `git pull`).

## 시장 스냅샷
요청 파일 첫 줄을 `#시장` 으로 쓰면 `tools/naver_market.py` 가 돈다. 둘째 줄부터 키워드.
네이버 쇼핑 등록 상품 수·가격대·판매처·브랜드와 데이터랩 쇼핑인사이트 연령·성별 비중을
`keywords/results/<이름>/00_시장.txt` 로 낸다. 판매량은 API 가 주지 않는다.

## 주제 추천
요청 파일 첫 줄을 `#추천` 으로 쓰면 계절 쇼핑 씨앗(패션·뷰티·생활가전·살림·운동·선물) 전체의 검색량을 모아
`keywords/results/<이름>/00_주제추천.txt` 로 낸다. 둘째 줄부터 씨앗을 더 넣을 수 있다.
